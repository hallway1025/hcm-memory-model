# HCM 记忆模型：形式化规格 v1.2

> 本文件是 HCM（Hippocampal–Cortical Complementary Memory）的**权威规格**。
> 与 docs/ARCHITECTURE-CORE.md（v1.0 契约）的关系：本文件是当前有效版本，凡冲突以本文件为准。
> 实测证据见 bench/ 与 results/，决策记录见 memory/20-DECISIONS.md。

---

## 0. 一句话定义

HCM 是一个**互补双系统**记忆模型：内侧颞叶用稀疏扩张码 + 现代 Hopfield 吸引子实现**一次性、情景级**存储；
新皮层用低秩前馈映射 + 级联突触可塑性实现**缓慢、统计级**存储；两者之间由锐波涟漪式的**优先级回放**搬运信息，
并由前额叶式**元控制器**决定编码 / 检索 / 巩固 / 遗忘 / 弃权。

模型的可执行参考实现是 src/hcm/（纯 NumPy，固定种子可复现），接口与参数在下文逐条给出。

## 1. 形式定义

    M = < X, Φ, E, S, W, Ψ, Π, Γ, G >

| 符号 | 名称 | 数学对象 | 生物对应 |
|---|---|---|---|
| X | 输入/情境空间 | x_t ∈ R^{d_x}，情境 c_t ∈ R^{d_c}，时间元 τ_t | 感觉皮层输入；内嗅皮层情境整合 |
| Φ | 编码器 | Φ: R^{d_x} → {0,1}^{d_h}（k-稀疏） | 内嗅皮层 II/III → 齿状回颗粒细胞 |
| E | 情节快存 | 稀疏码矩阵 M ∈ R^{d_h × N} + 元数据 | CA3 递归网络 |
| S | 语义慢存 | 低秩映射 f(x) = B tanh(Ax) | 新皮层锥体细胞突触权重 |
| W | 工作记忆 | C 个稀疏槽位 | 前额叶持续性放电，θ–γ 嵌套 |
| Ψ | 巩固算子 | 优先级回放 + 皮层 SGD | 锐波涟漪（SWR）驱动的系统巩固 |
| Π | 检索控制 | 三分支决策 recall / separate / abstain | 前额叶-海马检索模式控制 |
| Γ | 遗忘算子 | 剪枝 / 抑制 / 衰减 / 解除 | 突触修剪、检索诱发的暂时性遗忘 |
| G | 神经调质门控 | g_t = σ(w·[ν, r, ε, a] + b) | VTA 多巴胺、杏仁核、蓝斑去甲肾上腺素 |

单步动力学在 §11 给出完整伪码；各算子的定义在 §3–§10。

## 1.1 九个子系统与模块编号（索引）

本文件按**算子**组织（§3–§10），此处给出**子系统编号**到算子的映射，供与论文、`bench/ablation.py`、`results/g4_ledger.json` 对照。

| 模块 | 名称 | 脑底物 | 对应本文件章节 | 主要方程 |
|---|---|---|---|---|
| **M1_SEP** | 模式分离编码器 | 内嗅皮层 II/III → 齿状回颗粒细胞 | §3（3.1 期望库残差、3.2 扩张稀疏、3.3 双读出） | `u = unit(x − μ)`；`s = relu(W_e u + b_e − θ)`；`h = unit(kWTW(s,k))` |
| **M2_EPI** | 情节快存 | CA3 递归侧支 + CA1 | §4 | 写入 `M ← [M, g·h]`；检索 `z←unit(M·softmax(βMᵀz))` |

| **M4_CON** | 系统巩固 | 锐波涟漪（SWR）→ 皮层慢波 | §8 | `p_i ∝ recency^a·surprise^b·reward^c`，交错回放 |
| **M5_SEM** | 语义慢存 | 新皮层锥体细胞突触 | §5 | `f(x) = B tanh(Ax)`，级联可塑 + turnover |
| **M6_WM** | 工作记忆 | 前额叶持续放电，θ–γ 嵌套 | §6 | C 槽位，`w_j ← max(w_j + η_w(cos − mean), 0)` |
| **M7_NEU** | 神经调质门控 | VTA / 杏仁核 / 蓝斑 | §7 | `g_t = σ(w·[ν,r,ε,a] + b)` |
| **M8_FOR** | 遗忘与抑制 | 前额叶主动抑制、突触修剪 | §10 | 剪枝 `I_i = g_i e^{−Δt/τ}(1+use_i)`；RIF `sup ← (1−ρ)sup` |
| **M0_META** | 元控制 | 前额叶–海马环路 | §9 | 三分支：RECALL / SEPARATE / ABSTAIN，`raw_evidence = cos(s_q, D·a)` |

**消融结果摘要**（详见论文 §4.8 与 `results/g4_ledger.json`）：

## 2. 七条设计原则（每条都由实测支撑或推翻过一版）

1. **互补性不是「两套并行通路」，而是「两套读出」。**
   早期版本（ARCHITECTURE-CORE v1.0）让稀疏码与稠密码竞争同一个检索结果；实测（bench/exp1_separation.py）显示稀疏通路在高重叠输入上**从未赢过**。改为：编码器只负责产生稀疏码（写入用），检索用**同一投射的未取 top-k 版本**（稠密证据）做线性读出。同一权重，两种读出。

2. **分离（pattern separation）不在扩张、也不在阈值化，而在残差。**
   扩张 + k-WTA 只是把码变短；对共享期望成分做减法才把两个相似输入推到正交（overlap 0.90 时码余弦 0.872 → 0.308）。见 D-019 与 Table 1。

3. **稀疏性同时买到容量与去噪，代价是码书密度。**
   k 同时决定容量上界（N_max 与 d_h/k 同量级）与噪声鲁棒性（k 越小越脆）。

4. **写入由惊奇驱动**，不是由「是否被注意」驱动：门控 g_t 以新颖性、奖励预测误差、显著性和整体活动为输入。（exp41 边界：奖赏维度的功能贡献未获证明——重复过滤由 θ_dup 覆盖、新颖性维度的重复关闭与 θ_dup 功能冗余、RPE 连续响应被 θ_write 吸收；见 §7。）

5. **回放要按优先级**：p_i ∝ recency^a · surprise^b · reward^c（实测版本见 §8）。

6. **遗忘是功能，不是故障**：剪枝 + 检索诱发抑制（RIF）+ 语义衰减，且必须可被「解除抑制」部分逆转。（exp42 边界：情节剪枝算子在已测机制下**收益未获证明**——均匀奖赏分布下重要度剪枝与 FIFO 逐位同表现（rewarded 0.333 = FIFO 0.333）、集中奖赏块下 τ_f∈{50,500} 都保不住早期高奖赏块（0.0，g 提升 ≈0.2 压不过 e^{−Δt/τ} 衰减范围）；剪枝行为上等价于近因遗忘。RIF/存储级抑制的因果检验见 §10 与论文 §4.16/4.17。）

7. **弃权是一个合法输出**：当证据不足或存在未分离的竞争假设时，模型应输出 ABSTAIN 或 SEPARATE，而不是猜。
   - 边界（exp40，DailyDialog 公开语料）：train/test 同质的英语语料上 raw_evidence AUC=0.335（NEW256）/0.063（R512），均<0.5 且方向反转——**弃权门是分布移位检测器，不是库成员资格检测器**；适用条件=流式输入存在风格/来源漂移（论文 §4.20）。

## 3. 编码器 Φ：期望库残差 + 扩张稀疏 + 双读出

### 3.1 残差与期望库

输入先减去**慢变期望**，再编码：

    u_t = unit(x_t − μ^(j)) ,   j = argmin_j || x_t − μ^(j) ||

期望库 {μ^(j)}（B ≤ 8）以指数滑动平均更新：

    μ^(j) ← γ_μ μ^(j) + (1 − γ_μ) x_t ,   γ_μ = 0.9   # 慢速：每步只吃进 10% 新样本

> **更新次序（关键实现细节）**：残差 u_t 与新颖性 ν_t 一律用**更新前的旧 μ** 计算，随后才做上式的 EMA 更新（encoder.py `resid_write`：先 d=‖x−μ‖、ν_ema←0.9·ν_ema+0.1·d，再 μ←γμ+(1−γ)x）。若先用新 μ 算残差再更新，同一步的写入码与查询码会系统性失配。

**何时新建模板**（D-022 的核心，也是本项目踩过的最大坑）：仅用误差阈值会漏检。判据（任一成立即新建，新模板从 0 起步）：

- 突变：|| x_t − μ || > κ_jump · ν_ema，κ_jump = 1.5，ν_ema 为残差范数的指数平均；
- 方向反转：cos(x_t, μ) < 0.3 且 ||μ|| > 0.3。

> 为什么阈值不够：任务 A→B 切换时 d = 1.320、ν_ema = 0.701，比值 1.88 < 2.5；但方向余弦 −0.08 已无歧义地说明这是另一个情境。
> 为什么新模板必须从零起步：用首帧当模板会使该帧残差恒为 0，得到退化码（全零 → 无信息）。

### 3.2 扩张与稀疏化

    s_t = relu(W_e u_t + b_e − θ)        # 稠密证据（未取 top-k）
    h_t = unit( kWTW(s_t, k) )           # 稀疏码（写入用）

- W_e ∈ R^{d_h × d_x}，d_h = ρ d_x（默认 ρ = 8，d_x = 128 ⇒ d_h = 1024）；
- k = ceil(a d_h)，默认 a = 0.02（L0）；稀疏度 a 是「码书密度」，不是装饰参数；
- kWTW(s, k) 保留最大的 k 个分量、其余置零，然后 L2 归一。

**阈值 θ 只在发育期收敛，不在线漂移**（D-018）。在线 θ 漂移会破坏已写码的自洽性（同一输入在不同时刻得到不同码 → 检索系统性失配）。Encoder.develop(U, epochs) 用稳态机制（conscience）收敛：

    θ_i ← θ_i + η ( h_i − k/d_h )

> 注意符号：θ 必须作为**得分前的减项**才有「抑制强者」的效果；加到得分上会富者愈富并数值溢出（L-013）。


### 3.2a θ 协议（洁净复现第二轮后钉死，2026-11-07）

θ（每单元稳态阈值）在**主结果实验（表 3、exp14、§4.10 双读出）中恒为 0**：Config 不开 homeo、不调用 develop，s = relu(W_e u)。发育规则 θ_i ← θ_i + η(h_i − k/d_h) 有两种语义：
- **码值语义**（h 取单位化码值）：本配置下发散或坍缩——η=0.35、epochs=6、发育集=前 2000 条时精确召回 0.000（results/diag_theta_protocol.json，V1）；
- **二值占空比语义**（h_i 取 0/1 活动指示）：收敛到 k/d_h=0.0195（独立复现者实测，η=0.05）。

任何使用 develop/homeo 的实验必须声明：η、epochs、发育集、冻结时机、h 语义。θ 协议是**绝对数值的大敏感旋钮**（同一实验 0.000↔1.000 全域），定性方向（残差代价随 N 增长）在所有收敛协议下不变。

### 3.3 双读出

同一投射产生两个读出：稀疏码 h_t（写入 E、作为检索种子）与稠密证据 s_t（保留幅度，用于线性读出与吸引子初值）。
这不是两条通路，而是同一权重的两种用法。实测（bench/exp1_separation.py）：只用稀疏码做查询，30% 特征缺失时 top-1 = 8/20；用稠密证据做初值 + Hopfield 迭代，top-1 = 20/20。

## 4. 情节存储 E：现代 Hopfield 吸引子

写入（一次成形，无需迭代）：

    M ← [M , g_t h_t]     若 g_t ≥ θ_write

并保存元数据 (t_i, g_i, r_i, ν_i, use_i, sup_i, ctx_i, τ_i, payload_i)。

检索（连续迭代，每步重做 softmax 与归一）：

    z^(0) = unit( relu(s_ev) )
    a^(l)  = softmax( β M^T z^(l) )
    z^(l+1) = unit( M a^(l) )

- s_ev 是 §3.3 的稠密证据（**必须**用它做初值：以稀疏码为初值实测 17/30 vs 27/30）；
- β = 20，L = 3；L 过大（≥ 6）在混合态漂移，实测 19/30 → 2/30；
- 检索后的抑制权重 sup_i ∈ [0,1] 乘到 a 上，实现 RIF（§10）。
- **可选情境能量偏置**：softmax logits 加 ebias = κ·z(b_ctx)（Config.ctx_in_energy，默认关闭；经 β 放大的有效强度为 κ·β·z）。预登记标定（exp36c/d，论文 §4.18）：single κ=0.05 时时代锚定 P1≈0.80 且内容保护 P4≈0.92；multi-τ（τ∈{1,10,100,1000}）在匹配内容保护下严格更差（P1≈0.21）——默认关闭，作为检索控制 Π 的可选通路保留。

**容量**（bench/exp2*.py）：d_h = 1024、k = 20 时，N 从 30 到 1600 全部 exact 30/30 与 25% 缺失 30/30；推到 N = 16000（load = Nk/d_h = 312）exact 仍 20/20，25% 缺失降到 3–8/20。
**结论：瓶颈是去噪，不是条数**。残差在高重叠（有共享期望成分）数据上大幅提升，在随机正交数据上反而放大噪声。

> 真实语料边界（exp39，第六轮）：微信语料（David v2，deg0.3 弱退化探针）上残差开启 12/12 格命中略低（−1~−3/100）且写入变多（+40%/+21%）——窄带增益（share 0.85–0.92）在真实重叠分布上不出现，代价侧方向一致；β 转点跨编码器一致（≈20）。见论文 §4.21。

## 5. 语义存储 S：低秩前馈 + 级联可塑性

    f(x) = B tanh(A x) ,   A ∈ R^{d_z × d_x}, B ∈ R^{d_h × d_z}

联合梯度（无自动微分，手写）：

    δ = f(x) − h_target
    ∂L/∂B = 2 δ t^T
    ∂L/∂A = ( B^T 2δ ⊙ (1 − t^2) ) x^T

更新带**级联成熟度**调制（Benna–Fusi）：

    η_A,i = η / (1 + κ ω_A,i)
    ω_A,i ← ω_A,i + u_meta · 1[|∂A,i| > 0] · (1 − ω_A,i)

- κ = 8，u_meta = 0.02；成熟坐标变慢，从而在保留旧统计的同时保留少量可塑性；
- **突触更替（turnover）**：ω > 0.9 且仍被持续驱动 → ω ← 0。没有这一项，级联会把可塑性完全锁死（E4 首轮「B 全灭」的根因之一）；
- **梯度裁剪**：δ 夹在 [−3, 3]，∂A/∂B 夹在 [−1, 1]。不裁剪时 η = 0.2 在第 2 个周期就溢出到 inf。

**任务级目标**：在类别式持续学习里，h_target 取**类别码**（原型经 Φ 编码后的稀疏码），而不是样本自身，这样皮层学到的是「类」不是「例」。这一步是 E6 能出现教科书式遗忘曲线的关键（§8）。

## 6. 工作记忆 W：C 个槽位 + 权重竞争

- 槽位：C = 4（默认），每槽存一个稀疏码 h；
- 送码：若已有槽位与新码余弦 ≥ θ_same = 0.90，视为「同一记忆被复述」，该槽权重 +0.15；
- 否则占用空槽；无空槽时替换权重最低者，并按本次输入做权重竞争：

      w_j ← max( w_j + η_w ( cos(h_j,h) − mean cos ), 0 ) ,  η_w = 0.35

- 探针：max_j cos(h_j, q) > 0.5 判为命中。

## 7. 神经调质门控 G

    g_t = σ( w·[ν_t, r_t, ε_t, a_t] + b ) ,  w = (2.2, 1.4, 0.6, 0.8), b = −1.2

- ν_t：**相对期望偏离**（CA1 失配信号）。定义是
  ν_t = clip( (1 − cos(x_t, μ_j)) / EMA[1 − cos(x, μ_j)], 0, 2 )，
  即"当前输入偏离期望模板的程度"相对"近期平均偏离水平"的比值。
  （早期三代实现都用别的定义，全部失败，记录见 L-020：
   ||x − W_d h||/||x|| 动态范围仅 0.2%；1−cos(x, W_d h) 因 W_d 是秩 1 解码器而恒为 0；
   1−max cos(h, stored) 与模式分离结构性冲突，overlap 0.90 时把应存的新条目拒之门外。）
- r_t：奖励预测误差（标量 TD 误差，多巴胺）；
- ε_t：显著性（杏仁核/去甲肾上腺素，外部标量）；
- a_t = ||h_t||_1 / sqrt(k)：整体活动（蓝斑）。

实测（tests/smoke.py）：随机模式流下 g 均值 0.886，40/40 写入。
**代价**：门控无法区分「该记的」与「不该记的」，因为它只看惊奇。D-015 允许参数在文献区间内取值，但门控的**选择性**能力目前是模型的薄弱点。exp41 预登记重测（5 seeds）给出更强结论：M7 = **REDUNDANT-WITH-θ_dup**——(i) 重复过滤：门控与 θ_dup 功能冗余（任一单独足够，四格表见消融摘要）；(ii) 奖赏选择性：FS=0.05（门控臂与恒门臂的 P(write|r=1)−P(write|r=0) 之差）< 0.15 门槛，机制上 Δg≈0.2 的 RPE 响应存在但被 θ_write=0.5 的二值写入门限吸收——门控对写与不写的最终决策在全部测试协议下与恒门无差异。

## 8. 巩固 Ψ：优先级回放

一个「睡眠周期」= 对 E 中条目做 n_r 次加权抽样，每次把（线索，类别/目标码）送入 S：

    p_i ∝ ( e^{−Δt_i/τ_f} )^a · (g_i)^b · (1 + r_i)^c ,   τ_f = 50

默认 a = b = c = 1；周期内**交错**新样本与回放样本（interleave = 0.5）。

**实测（CLS 主张的正向证据，bench/exp6_continual.py）**：8 个原型类别 × 12 个带噪样本；先学 0–3 类，再学 4–7 类；d_z = 64，12 周期、每周期 24 个样本：

| 学习臂 | 旧任务（0–3 类）留出准确率 | 新任务（4–7 类）留出准确率 |
|---|---|---|
| blocked（只喂新任务） | **0/24** | 19/24 |
| uniform（新 + 旧样本各半） | **17/24** | 20/24 |
| priority（按 p_i 加权） | **17/24** | 20/24 |

即：不回放 → 旧任务被完全覆盖（教科书式灾难性遗忘）；交错回放 → 旧任务保住 71%、新任务不降。

**负结果 1（bench/exp6b_replay_buffer.py）**：把回放预算压到每周期 4 条、缓冲仅 6–24 条时，priority 并不优于 uniform（旧任务 3/24 vs 6/24）。**结论：本模型中「有交错」才是关键；我们没有找到 priority 优于 uniform 的参数区，如实报告。**

**负结果 2（bench/exp5_paired.py、bench/exp4c_capacity_pressure.py）**：当两套映射的目标码近正交（交叉余弦 0.02）、且 d_z 远大于任务数时，顺序学习**不产生**灾难性遗忘（同一线索 → 两套目标，blocked 臂旧任务仍 20/20）。
这说明：**遗忘不是模型的自动属性，而是「共享坐标 + 容量压力」的产物**；把它当成必然现象来论证 CLS 是错的（D-023）。

## 9. 检索控制 Π：三分支

证据融合分：

    f_i = λ a_i + (1 − λ) clip(s_i, 0, 1) ,   λ = 0.6

其中 a_i 是**概率向量**（Σ a_i = 1，峰值即置信度；早期版本误用 a/max(a) 归一，把置信度抹平导致恒判 separate，见 L-011），s_i = cos(f(x), h_i) 为皮层先验。

    RECALL   若 m1 ≥ θ_rec 且 m1 − m2 ≥ margin
    SEPARATE 若 m1 ≥ θ_rec 且 m1 − m2 < margin
    ABSTAIN  若 m1 < θ_rec

θ_rec = 0.25、margin = 0.06；代价敏感版本用 c_unit, c_err, c_abst 做期望代价最小化。

## 10. 遗忘 Γ

1. **情节剪枝**：重要度 I_i = g_i e^{−Δt_i/τ_f} (1 + use_i)，低于分位数且库满时删除最不重要条目。exp42（5 seeds，N=180/容量 60，预登记）：均匀奖赏分布下与 FIFO 保留集相同（rewarded 召回 0.333 两臂相等）；集中奖赏块（前 30 条 r=1）下 τ_f=50/500 都不能保护早期奖赏块（0.0）——g 的提升量（≈0.2）相对 e^{−Δt/τ} 的动态范围小两个量级，算子行为上等价于近因遗忘；「遗忘收益」未获证明（G-FB/G-FB2 FAIL，诚实边界）；
2. **检索诱发抑制（RIF）**：检索后对未被选中的竞争者施加 sup_i ← (1 − ρ_rif) sup_i，ρ_rif ∈ [0.05, 0.3]；只作用于 top-k 竞争者，且可被 disinhibit() 部分逆转。作用对象是检索证据读出、不改变存储模式；exp34 预登记因果检验（配对因果 Δ=−0.007，95%CI 含 0；v1 Δ=−0.023 同判决）证明当前参数化下不产生 below-baseline 遗忘——见论文 §4.16；存储级对照 exp34b（4 臂×12 seeds，预登记，v2 语料复跑同判决）：列幅值衰减产生 below-baseline 遗忘（0.158 [0.107,0.210]）但与练习项全局塌缩捆绑（0.080→0.157→0.430 随剂量单调），全量幅值逆恢复 gap 0.000——三难结论见论文 §4.17；
3. **语义衰减**：S 中未被使用的坐标以 η_dec = 0.02 向零收缩；
4. **解除抑制**：情境重访或成功再认把 sup_i 抬回 1。

## 11. 在线动力学：完整伪码

~~~text
输入: 流 (x_t, r_t, eps_t), t = 1..T; 超参见 §12
初始化: 期望库 MU = {0}; E 空; S 随机低秩; W 空

每步 t:
  1  情境  c_t = gamma_c * c_{t-1} + (1-gamma_c) * x_t          # gamma_c = 0.95
  2  残差  u_t = unit(x_t - mu[j])，必要时新建模板（§3.1）
  3  编码  s_t = relu(W_e u_t + b_e - theta);  h_t = unit(kWTW(s_t, k))
  4  惊奇  nu_t = clip((1 - cos(x_t, mu_j)) / EMA(1 - cos(x, mu_j)), 0, 2)
  5  门控  g_t = sigmoid(w·[nu_t, rpe_t, eps_t, |h_t|_1/sqrt(k)] + b)
  6  写入  if g_t >= theta_write: E.append(h_t, t, g_t, rpe_t, nu_t, ctx=c_t, tau=tau_t)
  7  工作记忆  W.present(h_t)
  8  检索（外部请求 q 时）
        for 每个期望模板 mu[j]:
            xe = unit(q - mu[j]); s_ev = raw(xe); q0 = encode_from_pre(pre(xe))
            ev = 归一(M^T s_ev); 取证据最大的模板
        a = Hopfield(M, s_ev, beta, L);  f = lam*a + (1-lam)*clip(cos(S(q), M),0,1)
        action = 三分支(f, theta_rec, margin)
  9  巩固（离线，每 K 步或睡眠期）
        抽样 p_i ∝ recency^a * surprise^b * (1+reward)^c
        S ← SGD(f, (x_i, h_target_i))，与新鲜样本交错，级联调制 + 裁剪
 10  遗忘  剪枝低重要度条目；对未选中竞争者施加 RIF；S 权重衰减
~~~

**逐数组存储核算（2026-11-07 修订；此前表行 d_h=524,288 与算式 65,536 不一致，现拆为核算档/外推档）**，d_h=65,536、d_x=8,192、N=2×10⁷：
- M（稀疏码，d_h×N fp32）稠密 5.24 TB → 稀疏列存 **210 GB**（k=1,311×8B/列）；
- **D（EC→CA3 直通稠密通路，同 d_h×N fp32）5.24 TB——D 才是存储瓶颈**：实测密度 51%，且依赖写入时刻编码器状态、无法离线重算（tools/verify_recompute2.py），稀疏化无效；fp16 减半至 2.62 TB；
- P（原始载荷，d_x×N fp32）655 GB（可外置原文存储按需解码）；
