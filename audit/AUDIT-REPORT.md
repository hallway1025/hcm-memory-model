## 3. 消融完整性（G4）

详见论文 §4.8。**9 个子系统：6 LOAD-BEARING / 1 REDUNDANT / 1 INCONCLUSIVE / 1 INERT。**

> 更正记录（第二轮独立审查 P1-1）：本句早期版本写「7 LOAD-BEARING / 1 REDUNDANT / 1 INERT」，漏了 INCONCLUSIVE，且是过期快照。现改为与 `results/g4_ledger.json` 一致的 6/1/1/1。

关键方法学发现：统一四指标会让 M3/M7/M8/M0 全部显示为无效，因为它们作用在别的因变量上。
本项目最终用 4 个统一指标 + 7 个专属指标才得到正确判定。

## 5. 本报告不能保证什么（对抗性自审）

必须明确列出，否则这份审计就是粉饰：

1. **不是独立复现。** 全部实验、代码、审计由同一条自动化流程完成，缺少第三方独立复现。真正的洁净复现（只给 README 与规格、不给实现者上下文）尚未执行。
2. **数字溯源只保证「论文数字 = 结果文件数字」，不保证「结果文件的方法是对的」。** 方法正确性靠 §4.8 的消融与消融暴露的实验 bug 兜底，但那仍不是证明。
3. **引文核验只验证文献存在与发表刊物，不验证「该文献支持此论断」。** 后者只能由作者负责；我们对每处引用都尽量贴近原文结论，仍可能有过度概括。
4. **全部实验用合成数据。** 机制层面的结论因此干净，但向真实数据的外推未经验证。
5. **M7 冗余、M8 惰性。** 这两个结论有实测支撑，但也意味着九个子系统里有两个在当前架构下没有承担独立功能。这是真实的架构缺陷，不是实验缺陷。
