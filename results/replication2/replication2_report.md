## 1. 实现要点（公式来源全部标注）

编码器与写入（每条样本 x）：
1. 期望库选择 `j = argmin_k ‖x − μ^(k)‖`（MODEL §3.1）。
2. 新模板判据：`d > 1.5·ν_ema` 或 `cos(x,μ) < 0.3 且 ‖μ‖ > 0.3`，新模板从 0 起步，B≤8（MODEL §3.1）。随机 iid 数据下实际始终单模板。
3. 残差（有残差臂）`u = unit(x − μ^(j))`；无残差臂 `u = unit(x)`；**先算残差、后做 EMA 更新** `μ ← 0.9μ + 0.1x`（G-8）。
4. 稠密证据 `s = relu(W_e u − θ)`（MODEL §3.2，b_e=0），`W_e ∈ R^{1024×128}` 取 QR 正交（PAPER §3.10）。
5. 稀疏码 `h = unit(kWTA(s, k=20))`（G-1）。
6. θ 发育：批量 conscience `θ_i += η(h_i − k/d_h)`（h_i 取 0/1 活动指示，G-4；η=0.05、≤100 epoch、早停；发育集=该种子库前 min(N,2000) 条；写入前发育、之后冻结，两臂共用同一 θ，G-3）。实测占空比精确收敛到 0.0195（36–53 epoch）。
7. 门控 `g = σ(2.2ν + 1.4r + 0.6ε + 0.8a − 1.2)`，`ν = clip((1−cos(x,μ_j))/EMA[1−cos], 0, 2)`，`a = ‖h‖₁/√k`，r=ε=0（G-12）；`g ≥ 0.5` 写入 `M ← [M, unit(h)]`（G-10，g>0 的标量缩放经单位化消失，与 PAPER §3.3「列归一化」一致）。实测所有设定下 g≈0.86，全部写入（written=N）。
8. 检索（PAPER §3.3）：`z0 = unit(relu(s_q))`；`a⁽⁰⁾ = softmax(βMᵀz0)`；循环 l=0..L−1：`z = unit(Ma)`，`a = softmax(βMᵀz)`，β=20、L=3；输出 `a⁽ᴸ⁾` 取 argmax。查询时库只读、用漂移后的 μ（G-6，MODEL §11）。
9. 稀疏读出：`h_q = unit(kWTA(relu(W_e u − θ)))`，`score = M·h_q` 逐行点积取 argmax。

种子协议（完全确定性）：`W_e` = `default_rng(1000+seed)` 的 QR；模式库 = `default_rng(100000·seed+N)`；探针/掩码 = `default_rng(10000000·seed+1000·N+{11,22,33})`。B 组两臂**配对**（同 perm 同 mask，取两臂已写交集——实测交集恒等于全集）。

## 3. 文档含糊点 / 冲突清单（本次复现最有价值的输出）

每条：出处 → 问题 → 我的选择（编号与 `your_impl.py` meta.choices 一致）→ 影响。

1. **k 值冲突**：MODEL §3.2 `k=ceil(a·d_h)`（a=0.02，d_h=1024）⇒ **21**；PAPER §3.2「k=20」、§8 表、§9.3 P2-3「代码实际 k=20」⇒ **20**。→ 选 **20**（G-1）。影响：可忽略（top-21 的第 21 个值通常极小）。
2. **稠密证据公式冲突**：MODEL §3.2 `s_t = relu(W_e u + b_e − θ)` vs PAPER §3.2 `s_t = W_e u + b_e`（无 relu）+ §3.3 `z0 = unit(relu(s_q))`；且 **b_e 无处给值**。→ 双模式都实现：主=MODEL（`relu(W_e u − θ)`，b_e=0，G-2/G-9），副=paper_raw（原始 `W_e u`）。影响：两种模式所有结果差 0–1 hit/格，可忽略——但文档应该写死一个。
3. **θ 发育规则严重欠定**（MODEL §3.2 + D-018）：`θ_i ← θ_i + η(h_i − k/d_h)`——(a) **η 未给**；(b) **h_i 语义未定**：若取单位化码值（激活值均值 ≈0.05–0.3），则 `h_i − k/d_h` 恒正（目标 0.0195），θ 单调上升直至全单元消亡——**规则在值语义下发散**；若取 0/1 活动指示，规则是标准的占空比平衡，收敛到 k/d_h=0.0195；(c) **发育集未定**（哪批数据？写入前还是流式？）；(d) 冻结时机只在 D-018 一句「发育后」。→ 选 **二值活动指示语义**（值语义数学上不收敛，是排除法）+ η=0.05 + ≤100 epoch 早停 + 发育集=该种子库前 min(N,2000) 条 + 写入前批量发育、随后冻结、两臂共用（G-3/G-4）。影响：**这是全部选择里最要命的一条**，直接决定码本稀疏度与缺失鲁棒性；第一轮教训 D-3 指认过，本文档仍未写明。
4. **ν_ema 与 EMA[1−cos] 的衰减系数/初值未给**：参数表只有 γ_c=0.95、τ_f=50，没有说这两个 EMA 用哪个（也不是 γ_c）。ν 的分母尺度直接改门控输入。→ 选衰减 0.9、初值 1.0（G-7）。影响：中——改 ν 尺度即改 g 分布；但 iid 数据单模板下 ν≈1，对写入判定（全写）不敏感。
5. **ν 定义冲突**：MODEL §7 `ν = clip((1−cos(x,μ_j))/EMA[1−cos], 0, 2)` vs PAPER §3.6 旧定义 `ν = ‖x_t − W_x h_t‖`（对重构的残差，还依赖一个 §7 没有的 W_x）。→ 按 MODEL（任务书指定 MODEL 为准）。影响：仅残差臂语义相关；本实验 iid 数据下 ν≈1，影响小。
6. **门控 r、ε 输入无实验对应物**：这批实验没有奖赏/显著性流。→ 取 0（G-12），g 实际 = σ(2.2ν + 0.8a − 1.2)。影响：无（文档本就该说明离线实验怎么置）。
7. **库初始化写法不一**：MODEL §11 `MU={0}` vs PAPER §3.10 `MU=∅`。→ 选 {0}（G-5）。影响：零——首个样本在两种写法下都触发「新模板从 0 起步」。
8. **残差与 EMA 更新的顺序**：MODEL §3.1 先给 u 公式再给 EMA 公式，暗示「先残差（用旧 μ）后更新」，但没写死；PAPER 未再提。→ 选先残差后更新（G-8）。影响：中——对慢漂移数据敏感；第一轮 D-2（EMA 方向写反）说明这类顺序错误真实存在。
9. **「无残差」臂没有定义**：文档没有 use_resid=False 模式。→ 选 `u = unit(x)`（跳过减法）、库照常更新（保证两臂除残差外全同）；查询时残差臂按 §11 用漂移后 μ（G-6）。影响：定义本身就是 B 组实验的语义基础，必须写进文档。
10. **模板满 B=8 后的行为未定义**：拒绝？替换最旧？合并？→选拒绝（G-7）。影响：本实验从未触顶（iid 数据单模板覆盖）。
11. **θ_dup=0.95 去重只在 PAPER §4.11 叙述出现**，不在 MODEL §4 写入规则里。→ 不实现（G-11）；iid 随机库下重复写入本来就不会触发。影响：无，但写规则不完整。
12. **存列是否带 g 缩放**：MODEL §4 `M ← [M, g_t h_t]` vs PAPER §3.3「M 的列是归一化条目码」。→ 选单位化列（G-10；g>0 标量单位化后消失，两者其实一致）。影响：无，但 §4 的写法会让人以为要存 g。
13. **表 3 / exp14 用哪个读出未说明**（稀疏读出 vs 稠密+Hopfield vs 稠密单步）。→ 主报稠密+Hopfield（MODEL §11 主检索路径）。影响：我的稀疏读出更高（B 组 1.000），不能解释 B 偏差。
14. **exp14 / 容量实验的模式库生成器没写**（PAPER §4.1 只给了 overlap 实验的 `x = unit(share·shared + (1−share)·priv)`，且 share=0.90 ⇒ 输入余弦 0.986±0.004——是强相关结构库）。任务书说「随机正交模式库」→ 我用 iid 高斯归一化。**若 exp14 实际用了非 iid 库（或 θ 发育流不同），B/C 的绝对难度完全不可比**——这是 B MISMATCH 的头号嫌疑，与第一轮 D-1 同源，至今未写。

## 4. B 组 MISMATCH 的讨论（只诊断，不回头调参）

按任务要求如实报 MISMATCH，未倒推修改实现。可能根因按嫌疑排序：

1. **模式库生成器（含糊点 14）**：我的库是 iid 随机正交方向。若论文 exp14 的库带结构（如 §4.1 生成器族），同样的 25% 置零对结构化模式的破坏更强，能同时压低两臂——与「我两臂同高、臂差形状在但幅度不足」的观察一致。第一轮洁净复现已把「生成器未写」列为 D-1，文档仍未补。
2. **θ 发育协议（含糊点 3）**：η、发育集、冻结时机的自由度足以把码本调得更鲁棒或更脆。我的协议（批量、库前 2000 条、占空比精确 0.0195）可能比论文的流式发育更稳。
3. **ν/EMA 超参（含糊点 4/8）**：只影响写入与残差中心，iid 下影响有限。
4. **读出选择（含糊点 13）**：排除——我的稀疏读出更高。
5. B@16000 诊断显示退化结构（N↑ 两者皆降、残差臂降更快）与论文同形、整体上移——更像系统性难度偏移而非实现错误。

**建议给作者的三个最小编补**：(a) exp14 的库生成器一行公式；(b) θ 发育的 η、发育集与 h_i 语义（码值 or 活动指示）；(c) 表 3/exp14 的读出方式与 ν_ema 衰减/初值。
