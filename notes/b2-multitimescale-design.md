# B2 设计：多时间尺度情境通道（M3 时间细胞升级，D-044 #3）

版本 v0.1 · 2026-11-07 · 起草 lead · 状态：设计稿；实现排在机1 CPU 空出后（exp35 全量 + opt-verify full2 之后）

## 1. 动机
- 薄弱清单 ①：M3 时间是最弱子系统——单尺度 γ=0.95、T_ctx=200、无时间细胞；exp28 链接是外挂（Wl 显式可塑性）。
- 调查 A 区（SURVEY-WEAKPOINTS.md）：TCM 漂移 S025、时间细胞 S002、多尺度突触 S041/S048（MMO 载具）；判词=「离散码多时间尺度需自适配」——正是空位。
- 与 LLM 记忆系统的差异化主战场：Mem0/HippoRAG 无生物时间尺度分层（J 区地图）。

## 2. 机制（对 MODEL.md §4 的增量）
- 现状：单通道 c_t=γ·c_{t-1}+(1-γ)·x_t，γ=0.95 → 有效记忆窗 ~1/(1-γ)=20 步；T_ctx=200 的高斯时间场只覆盖局部。
- B2：4 通道 EMA τ∈{1,10,100,1000}（τ=时间常数，γ_τ=exp(-1/τ)），编码输入扩为 [x; c1; c2; c3; c4]（d_x → d_x+4·d_tau 或共享 d_tau 压缩）；各通道独立噪声与幅度门（防干扰）。
- 检索端：多通道一致性入 M0——query 时四通道重建的情境码两两余弦均值作为新特征（与 exp35 的 cons 特征同型），供校准/弃权。

## 3. 预登记验收（借 S023 风格）
- P1（滞后依赖）：时序相邻探针对按 lag∈{10,10²,10³} 分桶；单 τ 基线在 lag≫20 步时前向联想→0（exp27 已证 1.5-1.7× 弱信号随距离衰减）；B2 在 lag=100/1000 桶保持显著高于随机基线。
- P2（内容不回归）：内容召回（exp22p 判据）相对单 τ 基线不降 >2%（守门：时间信号不得以内容为代价）。
- P3（通道消融）：逐通道去掉，P1 效应单调退化；τ=1000 通道单独负责远程桶。
- P4（校准联动）：多通道一致性特征加入 exp35 特征集 C → ECE 进一步下降且 AUC 不降（与 G-2 同型）。
